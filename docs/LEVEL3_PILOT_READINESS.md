# Level 3 Pilot Readiness

The readiness assessment checks official annual reports, financial statements, guarantee activity, terms, claims, recoveries, beneficiaries, source languages, historical series and comparability risk.

| Institution  | Readiness       | Main caution                                                   |
| ------------ | --------------- | -------------------------------------------------------------- |
| JFC          | ready           | Keep SME credit insurance separate from direct lending         |
| ACGF         | ready           | Map Taiwan fiscal-year and agriculture-policy definitions      |
| TSMEG        | ready           | Fix indicator and fiscal-year mappings before collection       |
| KOTEC        | partially ready | Confirm recovery definitions and technology-appraisal boundary |
| CGC Malaysia | partially ready | Obtain official claim and recovery definitions                 |

Readiness authorizes no data publication. A pilot still requires a reviewed source map, indicator-by-indicator definition match, currency/time metadata and human verification.
